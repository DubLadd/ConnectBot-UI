ConnectBot UI & Server Dashboard SimulatorThis project is a front-end UI demonstration of a Client-Server network model, inspired by the popular Android SSH app, ConnectBot.It consists of two interactive web interfaces built to visualize how a mobile client connects to a local laptop server.📱 The Client: ConnectBot Mobile UI (index.html)A faithful recreation of the ConnectBot "Add Host" screen.Features: Dark mode aesthetic, Material Design toggle switches, expanding advanced options accordion, and interactive form validation.Purpose: Represents the user's mobile phone attempting to connect to a remote host.💻 The Server: Laptop Host Dashboard (server_dashboard.html)A custom-built dashboard representing the laptop waiting for an incoming connection.Features: Server toggle (Start/Stop), real-time simulated terminal logs, active client tracking, and a "Simulate Connection" trigger.Purpose: Represents the machine opening a port and listening for the mobile phone's SSH request.🛠️ Technologies UsedHTML5 & Vanilla JavaScript (No heavy frameworks or backend required)Tailwind CSS (via CDN for rapid styling and responsive design)Lucide Icons (for clean, modern SVGs)🚀 How to Run LocallyBecause this project is a purely front-end simulation, you don't need to install any servers or dependencies!Clone or download this repository.Double-click index.html to open the Mobile App UI in your browser.Double-click server_dashboard.html to open the Laptop Server UI in your browser.Try clicking "Start Server" and then "Simulate Phone Connection" on the dashboard to see the interactions!📸 Previews(Note: You can add screenshots of your interfaces here later!)![Mobile UI](link-to-image)![Server UI](link-to-image)
